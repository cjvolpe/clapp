# CLAPP 👏
Clapp serves as a catalog for the climbs at the UNC-CH rock climbing walls. Users are able to view both the current and former climbs on the climbing walls and track completed climbs.
## Inspiration 💡
The idea for Clapp stems from the online forum Mountain Project, which is used for finding and tracking climbs outside. However, there lacks an established method for tracking and managing gym climbs. This the problem that Clapp is addressing.
## Future🧗
Currently users are able to do the following: 
- Add & Log Climbs
- Search through the climbing catalog by route name
- Search by properties of the climb (e.g. Gym Location, Date Set, Grade Range)

The following are features that are planned to be added in the near future:
- Differentiate between permission levels
  - Only admins should be able to add climbs
  - Part of this is creating a method of submitting and approving made up boulders (MUBs)
- Switch to Microsoft OAuth
  - ONYENs use Microsoft logins 
- Redo frontend theme/style
  - Not a fan of the cartoony style anymore
- Data Analysis and Admin Panel
  - Visualize the grade range of routes on the wall and use that to make informed decisions regarding route setting
